# Правила работы с проектом API-rope-shop

## Границы работ

- Работаем **только с фронтендом**: `frontend/` (HTML, CSS, JS, скрипты).
- **Бэкенд (`backend/`) не трогаем вообще**: не переписываем код, не правим конфиги, не «улучшаем» его.
  Читать бэкенд для понимания контрактов API — можно.
- Если по ходу работы найдена ошибка/проблема на бэкенде — **не исправлять**, а записывать
  в отдельный файл `BACKEND_ISSUES.md` в корне проекта, чтобы отправить бэкендеру.

## Файл для багов бэкенда

`BACKEND_ISSUES.md` — журнал найденных проблем бэкенда. Для каждой записи:

- дата;
- где воспроизводится (страница/сценарий на фронте);
- эндпоинт и метод;
- что ожидалось / что реально пришло (статус, тело ответа, консоль);
- предположительная причина (если видна по коду, но код не правим).
