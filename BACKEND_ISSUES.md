## [2026-11-05] Сеялка создаёт записи ProductImage на несуществующие файлы

- Где: админка/каталог, после `docker compose exec backend_rope_shopo python -m src.tools.create_test_data`
- Эндпоинт: `GET /api/products` (поле `main_image_url`), далее запрос картинки
- Ожидалось: картинки товаров открываются
- Фактически: `create_test_data.py` прописывает `main_image_url = /assets/products/<name>.webp`, но в `media/products/` этих файлов нет. nginx алиасит `/assets/` → `/app/media/`, поэтому запрос отдаёт **404**. У всех 6 товаров из сеялки битые фото.
- Предполагаемая причина: тестовые данные ссылаются на файлы, которых нет в репозитории (`media/` не содержит этих webp). Нужно либо добавить изображения, либо генерировать их в сидере.
- Проверено: `http://localhost/assets/products/cruising_pes_1.webp` → 404.
