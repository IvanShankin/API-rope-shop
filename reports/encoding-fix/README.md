# Исправление кодировки: frontend/index.html и frontend/catalog.html

Дата: 2026-11-05. Ветка dev, HEAD 83e2d2a (коммит не делался — правки в рабочем дереве).

## Что было сделано

Оба файла в коммите 83e2d2a были записаны двойной перекодировкой
UTF-8 → CP1251 → UTF-8 («РљР°С‚Р°Р»РѕРі» вместо «Каталог»).
Выполнено точное обратное преобразование, построчно, с strict-проверкой UTF-8
(невалидные последовательности не трогались бы):

```
text → CP1251.GetBytes → UTF-8 strict decode → исходный текст
```

Запись: `[System.IO.File]::WriteAllText` с `UTF8Encoding($false)` — UTF-8 без BOM,
переводы строк CRLF сохранены (их было CRLF в рабочем дереве, в git-блобе LF,
`core.autocrlf=true` — поведение git при коммите не изменится).

## Доказательства, что вёрстка не пострадала

1. `git diff --numstat`: `95 95` и `52 52` — добавлено столько же строк, сколько
   удалено, число строк в файлах не изменилось.
2. Рабочие файлы **побайтово равны** `repair(HEAD-blob) + CRLF` — т.е. единственное
   отличие от закоммиченного состояния это само обратное преобразование; теги,
   классы, структура, спаны скелетов каталога не изменились ни на байт.
3. Сверка с версией до поломки (`git show 96568b3`): после исключения разницы
   CRLF/LF отличий от 96568b3 ровно одно на файл — намеренное `style.css?v=20261105.1`
   → `?v=20261105.2` из коммита 83e2d2a. Все русские фразы совпадают с до-поломочной
   версией построчно.
